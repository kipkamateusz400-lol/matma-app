# Matma – dzienna dawka zadań maturalnych

Aplikacja Android (WebView) z codziennym zestawem zadań z matematyki (podstawa + rozszerzenie).
APK buduje się automatycznie przez GitHub Actions po każdym pushu; gotowy plik jest w zakładce **Releases**.
Cała aplikacja to `app/src/main/assets/index.html`.
